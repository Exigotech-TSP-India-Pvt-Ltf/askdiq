## What the ACSC Essential Eight Is

The ACSC Essential Eight is a set of eight mitigation strategies designed to **reduce the likelihood of cyber compromise and limit the impact of security incidents**.

It focuses on **practical, high-value controls** addressing common attack techniques and operational risks. The framework is structured around defined maturity levels, enabling organisations to **progress security posture in line with business priorities**.

#### Application Control
Application control ensures that only approved applications are allowed to run, reducing the risk of malicious execution and limiting the impact of unauthorised software.

_(Selected: "Patch Applications")_
#### Patch Applications
Regular application patching closes known vulnerabilities before attackers can exploit them, significantly reducing your attack surface.

_(Selected: "Configure Macros")_
#### Configure Macros
Macro-based attacks are a common vector for malware. Proper macro configuration prevents unauthorized code execution.

_(Selected: "User App Hardening")_
#### User App Hardening
Browser and application hardening reduces the attack surface by disabling unnecessary features and blocking known risky content.

_(Selected: "Restrict Admin Privileges")_
#### Restrict Admin Privileges
Limiting admin access ensures that compromised accounts have minimal impact and reduces the risk of privilege escalation attacks.

_(Selected: "Patch Operating Systems")_
#### Patch Operating Systems
OS patches address critical vulnerabilities that attackers frequently target. Timely patching is essential for maintaining security.

_(Selected: "Multi-Factor Auth")_
#### Multi-Factor Auth
MFA adds an additional layer of security by requiring multiple forms of verification, significantly reducing the risk of unauthorized access.

_(Selected: "Regular Backups")_
#### Regular Backups
Regular, tested backups ensure business continuity in the event of ransomware attacks, data corruption, or system failures.
